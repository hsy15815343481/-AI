# 去 AI 感 · 真实感提示词规范（V1）

> 适用：文生图、图生图、商品 / 穿搭 / 场景 / 视频出片。目标是让 AI 出片更接近实拍，减少蜡感、塑料感、过曝、畸形等典型 AI 痕迹。
> 配套代码片段：`src/lib/realism.js`；模型真实感倾向标注见 `src/lib/modelCatalog.js`。

## 一、核心思路

1. **先讲清楚主体与场景**：商品、人物、服装、环境、机位，描述越具体越不容易跑偏。
2. **再补真实感锚点**：光线、纹理、构图、颗粒、投影，对齐实拍照片的成像规律。
3. **最后写反向约束**：明确规避典型 AI 问题。当前渠道多为纯文生图，反向约束以「避免：……」并入提示词正文，不依赖独立 negative 字段。

> 真实感最终仍受接入模型本身能力限制；提示词锚点只能缓解，不能把弱模型变强。模型选型与渠道开通是前置条件（见待办 #57）。

## 二、正向锚点库（按场景挑选 3–4 条，不要全堆）

### 通用
- 单侧自然光源，明暗过渡柔和
- 保留真实皮肤与面料纹理，可见自然毛孔与织物纹路
- 非居中的自然构图，带少量生活场景细节
- 轻微胶片颗粒，画面不过度锐化
- 阴影方向与光源一致，投影自然落地
- 材质反射符合真实物理规律

### 商品 / 主图补充
- 面料走线、纽扣、logo 等细节清晰可辨
- 边缘干净利落，无发虚描边
- 背景纯白或干净浅色，无多余杂物

### 穿搭 / 人像补充
- 姿势自然放松，无僵硬摆拍感
- 服装版型合身，褶皱符合人体与布料重力
- 肤色自然，不磨皮到失去皮肤纹理

### 场景图补充
- 环境有真实使用痕迹（桌面、街道、居家细节）
- 人与商品比例协调，透视正确

## 三、反向约束库（尾句统一以「避免：」开头）

- 蜡感或塑料质感皮肤
- 全域过曝、高光溢出
- 过度磨皮、五官失真
- 畸形肢体、手指错乱
- 虚假光影、贴图感
- AI 塑料质感、边缘模糊发虚

## 四、分场景套用结构

### 1. 商品主图（白底 / 浅色底）
> 主体：____（品类 / 款式 / 颜色）；背景：纯白干净；光线：单侧柔和均匀、无硬阴影；构图：主体居中占画面约七成，材质细节清晰；真实实拍质感：自然光源、织物与材质纹理、轻微颗粒；避免：塑料质感、过曝、边缘发虚。

### 2. 穿搭 / 模特上身
> 服装：____；模特：____（性别 / 体型 / 风格）；姿势：自然站立或日常走动；场景：简洁街拍或纯色背景；光线自然，版型与颜色还原准确；真实皮肤与布料纹理可见；避免：磨皮失真、蜡感皮肤、僵硬姿势。

### 3. 产品场景图
> 主体：____；使用场景：____（街头 / 居家 / 办公室 / 户外）；商品为视觉中心，场景做衬托；自然日光，环境带真实生活细节；构图自然不刻意居中；避免：贴图感、虚假光影、过曝。

### 4. 商品视频
> 主体：____；镜头：缓慢环绕 / 推拉展示整体与细节；背景干净，光线均匀；节奏轻快，动作连贯自然；避免：画面跳变、光影闪烁、人物或物体变形。

## 五、使用注意

- **锚点不要堆叠过多**：一条提示词正向锚点 3–4 条即可，过多会互相冲突、拉长生成时间。
- **不依赖独立 negative 字段**：当前后端渠道按纯文生图入参，反向约束并入正文尾句；后续若渠道支持独立 negative prompt，再拆分到对应字段。
- **去重**：基础描述里已经写过的锚点（如「真实皮肤纹理」）不要在尾句重复。
- **模型分级**：模型目录中 `realism` 字段标注真实感倾向（`high` 写实 / `medium` 通用 / `experimental` 待实测）；默认优先推 `high`，出片后按实测效果校正分级。
- **实测校正**：每次大批量出图后，记录哪种模型 + 锚点组合最接近实拍，回填到本规范与模型目录。
