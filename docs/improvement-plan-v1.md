# AI 工具箱 UI / 工作流 / 模板市场改进计划（V1）

> 状态：**P0 / P1 已落地；P2 本轮完成空白引导、真实感规范、模板后端化最小骨架；D1 完整运营化随 BaaS 联调后续落地**（实施记录见文末第七节）。
> 对标产品：创米 AI（工作流画布、节点连线）、蕉点 AI（指令模板一键复用、整体深色科技感）。
> 最近更新：2026-11-25

---

## 一、整体目标

1. 首页去掉重复、冗余的入口区块，只保留核心创作区 + 模板市场。
2. 模板市场拆成两个并列模块：**指令直接用**（提示词/文案模板）+ **工作流模板**（预置流程可整套复用）。
3. 工作流画布对齐创米 AI：窄竖工具条、点「添加」才展开节点清单、磁吸加号连线、节点参数集中。
4. 全站 UI 统一为深色科技感，消除「顶部亮黄横幅 + 黑色侧栏 + 中间大白空白」的割裂感。
5. 沉淀一套「去 AI 感」的模型选型 + 提示词规范，固化到模板里。

## 三、改动清单

### A. 首页结构精简（对标蕉点 AI）

#### A1. 移除首页「最近项目」区块
- **现状问题**：首页重复展示历史作品，后续统一收口到「我的作品」页即可。
- **目标方案**：
  - 删除 `HomeView.vue` 中「最近项目」整段 `section`（模板、样式、`recent` 计算属性及相关空态逻辑）。
  - 历史作品只在 `/works`（`WorksView.vue`）查看，侧边栏入口保留。
- **涉及文件**：`src/views/HomeView.vue`
- **优先级**：P0
- **验收**：首页不再出现最近项目卡片；登录后历史作品在「我的作品」页完整可见。

#### A2. 移除对话框下方重复的快捷功能胶囊
- **现状问题**：首页 `quick-caps` 那排胶囊与侧边栏 `SidebarQuickTools` 是同一批入口，重复占位。
- **目标方案**：
  - 删除首页 `.quick-caps` 整段按钮组及对应样式；`QUICK_TOOLS` 仅由侧边栏使用。
  - 首页创作卡内保留类型 / 模型 / 比例分辨率等生成参数控件（这是创作必需，不是重复入口）。
- **涉及文件**：`src/views/HomeView.vue`、`src/lib/quickTools.js`（清理未用引用）
- **优先级**：P0
- **验收**：首页创作区下方直接接模板市场，无第二排功能胶囊；侧边栏功能入口不受影响。

#### A3. 对话框下方直接是模板市场，分两个并列模块
- **现状问题**：现有模板市场只有一类静态预设，缺少「指令模板」与「工作流模板」的区分。
- **目标方案**：
  - 模板市场顶部做两个并列 Tab / 分区：**指令直接用**、**工作流模板**。
  - **指令直接用**：
    - 卡片为可视化预览卡（封面 + 标题 + 描述 + 标签），点「一键做同款」跳转到创作页，自动回填预设提示词、模型、比例/分辨率/数量等参数，用户可修改后再生成。
    - 模板内容后续可由管理员后台上传/维护（见 D1）。
  - **工作流模板**：
    - 卡片对应一套预置好的工作流（节点 + 连线 + 各节点参数），点进去直接进入工作流画布并加载整套流程，可二次编辑、运行。
    - 后续上线开放给其他用户复用；先把现有「穿搭模板」沉淀为第一张工作流模板卡。
- **涉及文件**：`src/views/HomeView.vue`、`src/lib/presets.js`、`src/stores/workflow.js`、新增模板卡片组件（建议 `src/components/templates/`）
- **优先级**：P1（首页结构精简后紧接着做）
- **验收**：
  - 两个模块可切换；指令模板点击后创作页参数被正确回填；工作流模板点击后画布加载对应节点与连线。
  - 卡片支持分类筛选与搜索（沿用现有 `activeGroup` / `keyword` 逻辑）。

### B. 工作流画布改造（对标创米 AI）

#### B1. 左侧改为窄竖工具条，点「添加」再展开节点清单
- **现状问题**：左侧 200px 宽节点列表常驻，占画布空间；节点类型（文本/图片/音频/视频/其他资源）一进来全摊开。
- **目标方案**：
  - 默认只保留一条贴左的窄竖工具条（图标为主），不放宽列表。
  - 点「添加」（或展开按钮）后才弹出/展开节点选单，分组展示：文本、图片、音频、视频、其他资源/辅助节点。
  - 选单支持点击添加，也保留拖拽到画布。
- **涉及文件**：`src/views/WorkflowView.vue`、`src/lib/workflow.js`（节点分类补全：音频/视频节点当前参数较占位，需补齐）
- **优先级**：P1
- **验收**：未展开时画布留白最大化；展开后能看到全部节点类型并可添加；窄竖条不遮挡画布主区域。

#### B2. 磁吸加号连线（解决现在连线难找端口的问题）
- **现状问题**：现在要手动从节点右侧端口拉线到下一节点左侧端口，端口不明显、连线麻烦。
- **目标方案**：
  - 选中节点后，拖拽朝向目标节点；靠近目标节点时在其吸附点浮现「+」小加号。
  - 松手即自动连上曲线，无需手动找端口；重复连线去重逻辑沿用现有 `onConnect`。
  - 保留端口可拖拽作为兜底，但主路径走磁吸吸附。
- **涉及文件**：`src/views/WorkflowView.vue`、`src/stores/workflow.js`、`@vue-flow/core` 连接交互配置
- **优先级**：P1（核心体验痛点）
- **验收**：从 A 节点拖向 B 节点，靠近出现加号提示，松手自动成线；连线方向正确（A→B）；重复连接不产生重复边。

#### B3. 图片节点参数集中化
- **现状问题**：图片相关参数分散，上传、提示词、模型、比例、清晰度、数量未集中呈现。
- **目标方案**：在图片 / AI 绘画节点（及右侧参数面板）集中提供：
  - 提示词输入框；
  - 参考图上传（图片节点）/ 图片链接兜底；
  - 模型选择；
  - 画幅比例；
  - 清晰度/分辨率档位；
  - 生成数量。
- **涉及文件**：`src/views/WorkflowView.vue`、`src/components/workflow/WfNode.vue`、`src/lib/workflow.js`
- **优先级**：P1
- **验收**：图片类节点的上述参数均可在节点/参数面板内设置并随工作流提交生效。

#### B4. 空白画布初始态
- **现状问题**：新画布进入后缺少明确的空态引导。
- **目标方案**：进入新工作流时为深色点阵画布，中间留白，提示「双击 / 点添加节点开始搭建」。
- **涉及文件**：`src/views/WorkflowView.vue`
- **优先级**：P2
- **验收**：空画布有明确引导提示，点阵背景与整体深色主题一致。

### C. 全站 UI 主题统一（深色科技感）

#### C1. 去掉亮黄横幅，统一深炭灰基调
- **现状问题**：顶部亮黄横幅（`#f5ee5a`）、黑色侧栏、浅色主区三套色调，割裂感强。
- **目标方案**：
  - 顶部横幅改为与侧栏同色系的深炭灰（建议 `#12151b` / `#1c1917` 一档），品牌名与标语用浅色字；亮黄仅保留为极少量点缀（如关键红点），不再大面积铺色。
  - 主内容区由大白底改为深色/极浅灰深色调，背景加细微点阵或网格，与工作流画布一致。
  - 品牌主色用低饱和蓝/青渐变做按钮、选中态、强调色；统一一套 CSS 变量，不再局部写死颜色。
- **涉及文件**：`src/assets/main.css`（主题变量）、`src/App.vue`（横幅/侧栏/主区）、`src/views/*.vue`、各组件样式
- **优先级**：P0（先统一基调，再做功能改造）
- **验收**：
  - 全站背景、侧栏、卡片、输入框、按钮在同一深色体系内，无突兀亮色块。
  - 文字对比度可读；Element Plus 浅色覆盖变量同步改成深色适配。
  - 工作流画布与首页色调衔接自然。

#### C2. 卡片 / 控件配色协调
- **现状问题**：卡片边框、填充、按钮深浅不一。
- **目标方案**：基于新主题变量统一卡片表面、边框、悬浮态、禁用态；模板卡片、参数面板、弹窗跟随同一套层级色。
- **涉及文件**：`src/assets/main.css`、各 `*.vue` 组件
- **优先级**：P1
- **验收**：全站同类控件观感一致，悬浮/选中/禁用状态清晰可辨。

### D. 模板内容与「去 AI 感」体系

#### D1. 指令 / 工作流模板后台可维护（后续）
- **现状问题**：模板静态写死在 `presets.js`，改模板要改代码发版。
- **目标方案**：
  - 模板数据结构与现有 `PRESETS` 对齐，逐步迁移到后端/Supabase 存储，支持管理员新增、编辑、上下架。
  - 工作流模板保存为可序列化的节点 + 连线 + 参数集合，加载时反序列化回画布。
- **涉及文件**：`src/lib/presets.js`、`src/stores/workflow.js`、`server/`（mock/后端接口）、Supabase 表结构（参考 `docs/supabase-migration.md`）
- **优先级**：P2（前端卡片与跳转链路先通，后台化后补）
- **验收**：不发版即可新增一条指令模板/工作流模板并在首页展示复用。

#### D2. 模型选型与提示词「去 AI 感」规范
- **现状问题**：不同模型出图 AI 感轻重不一，目前未区分、模板内也无统一质感约束。
- **目标方案**：
  - **模型侧**：在模型目录标注真实感倾向（写实/人像/电商场景适配），优先接入出图真实感强的渠道；后续按出片效果分级排序。
  - **提示词侧**：在图片类模板固化真实感锚点 + 反向约束，例如：
    - 正向：单侧真实光源、自然皮肤/面料纹理、轻微胶片颗粒、非居中自然构图、真实生活场景细节。
    - 反向：蜡感/塑料皮肤、全域过曝、过度磨皮、畸形、虚假光影、AI 塑料质感。
  - 提示词规范沉淀为一份可复用模板片段，供图片/视频模板引用。
- **涉及文件**：`src/lib/modelCatalog.js`、`src/lib/presets.js`、`src/lib/workflow.js`（节点默认提示词）、新增提示词规范文档（建议 `docs/prompt-realism-guide.md`）
- **优先级**：P2（随模板内容一起沉淀）
- **验收**：同一商品用模板出图，皮肤/面料/光影更接近实拍；模板内自带真实感锚点与反向约束。

## 五、拍板结论（2026-11-26 已逐条确认）

1. **全站基调**：**维持深色科技感**，不改回浅色主区；亮黄横幅已去除，后续不做浅色改版。
2. **模板市场形态**：**维持顶部 Tab 切换**（指令直接用 / 工作流模板），不改成上下并排分区。
3. **工作流模板复用范围**：**预留公开字段**（作者 `author`、可见范围 `visibility`）；第一版默认私有，字段先落数据结构与后端兜底，后续开放给其他用户复用。
4. **图片参考图上传**：**先做 UI 预留**——首页上传框与工作流图片参数面板放禁用入口与待接入提示；图生图/参考图渠道接通后再放开。
5. **模型真实感分级**：**暂不出对比清单**；`realism` 分级保持占位标注，待真实渠道出片后实测回填。
6. **智谱免费视频渠道**：**现在接上**（`cogvideox-flash`，复用 `ZHIPU_API_KEY`），已完成后端联调并真实出片。

## 六、风险与边界

- **主题改造牵连面广**：Element Plus 组件大量使用浅色覆盖变量，改深色需逐个核验输入框、下拉、弹窗、表格、空态的对比度，避免文字看不清。
- **磁吸连线依赖 Vue Flow 能力**：需先验证 `@vue-flow/core` 是否支持靠近吸附点高亮/加号，若不支持需用自定义端点 + 拖拽监听实现，工作量会上浮。
- **工作流模板序列化**：节点上若挂了不可序列化的对象（如临时图片 dataURI 过大），保存/加载需做裁剪与兜底。
- **真实感效果受模型渠道限制**：提示词锚点只能缓解，最终质感仍取决于接入模型本身；模型选型与渠道接入是前置条件。
- **本计划不含**：积分计费规则调整、登录/权限体系改造、移动端适配重做（如需要另立条目）。
